# Emilio Medrano — Portfolio

Personal portfolio for **Emilio Medrano**, a musician, composer, producer, educator, and software engineer based in Miami.

The current site focuses on original music, film/game scoring, arrangements, production, and performance work. It is being expanded into a broader **Music × Software × AI** portfolio with case studies for creative-technology projects and AI-assisted music workflows.

## Current portfolio content

- Cinematic / emotional music
- Adventure, fantasy, and game music
- Epic / action cues
- Dark / suspense music
- Retro / chiptune work
- Pop arrangements and production
- Piano / intimate music
- Lo-fi / chill music
- Selected releases and collaborations
- Game credits and sound-design work
- Music services and contact information

## Tech stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Motion
- Lucide React

## Local development

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
