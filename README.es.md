# Emilio Medrano — Portafolio

Portafolio personal de **Emilio Medrano**, músico, compositor, productor, educador e ingeniero de software en Miami.

El sitio actual se centra en música original, scoring para cine/videojuegos, arreglos, producción y performance. Se está expandiendo hacia un portafolio más amplio de **Música × Software × IA**, con casos de estudio de proyectos creativo-tecnológicos y flujos de trabajo musicales asistidos por IA.

## Contenido actual del portafolio

- Música cinematográfica / emocional
- Música de aventura, fantasía y videojuegos
- Cues épicos / de acción
- Música dark / de suspenso
- Trabajo retro / chiptune
- Arreglos y producción pop
- Piano / música íntima
- Lo-fi / chill
- Lanzamientos y colaboraciones seleccionadas
- Créditos de videojuegos y diseño de sonido
- Servicios musicales e información de contacto

## Stack tecnológico

- React 19
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Motion
- Lucide React

## Desarrollo local

```bash
npm install
npm run dev
```

Build de producción:

```bash
npm run build
```

## Dirección del portafolio

La siguiente iteración conectará el trabajo musical de Emilio con sus proyectos de software e IA, incluyendo:

- Investigación de audio asistido por IA → cifrados / MusicXML
- Herramientas de tecnología musical
- Plataformas de colaboración creativa
- Software de educación musical
- Analítica personal / sistemas de apoyo a decisiones
